#  Python Programming Laboratory
### From Fundamentals to Functional Programming

*A collection of five Python laboratory experiments, developed and documented using Jupyter Notebooks in Visual Studio Code.*


---

## ✨ About This Repository

Welcome to my Python Programming Laboratory!

This repository documents my practical exploration of Python programming, from fundamental syntax and data types to functions, recursion, modules, regular expressions, file handling and exception management.

Each experiment includes:
- 📖 Clear explanations of programming concepts
- 💻 Python programs with meaningful examples
- 📊 Executed code cells and outputs
- 🧩 Practical applications of programming concepts
- ✅ Experiment-wise conclusions

The objective is not only to implement Python concepts, but also to understand how they can be applied to solve real-world problems.

## ▶️ How to Run the Experiments

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Python and Jupyter extensions if required.
4. Open any `.ipynb` experiment file.
5. Select a Python kernel.
6. Run the notebook cells in sequence.

**Note:** Experiment 4 requires its supporting Python modules and package. Experiment 5 creates and uses local text files.
